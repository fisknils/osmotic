# feature/npm-keywords

## Prompts

1. The maintainer added a `keywords` field to `package.json` (`osmotic`, `scraper`, `crawler`, `headless`,
   `javascript-rendering`) while Claude was reporting on issue triage.

   > commit package.json, push, open pr, merge

## Interpretation

Add the `keywords` field to `package.json` as written, so the package is easier to find on npm, through a pull request.

## Type

Other (package metadata).

## Version bump

None. The keywords reach npm with the next published version.
